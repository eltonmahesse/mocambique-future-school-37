# Colégio Pércia

Site institucional estático em HTML5, CSS3 e JavaScript Vanilla.

## Estrutura

- `index.html`: página principal e markup semântico.
- `css/styles.css`: estilos próprios e responsividade.
- `js/main.js`: menu, carrosséis, modal de vídeo e formulário.
- `imagens/`: imagens e vídeos usados pela página.
- `lovable-uploads/`: logotipo do Colégio Pércia.
- `favicon.ico`, `placeholder.svg` e `robots.txt`: assets públicos na raiz.

## Executar

Abra `index.html` diretamente no navegador. O Tailwind CSS é carregado pelo CDN no próprio HTML; não é necessário instalar Node.js ou qualquer dependência.

Para usar um servidor local opcional:

```powershell
python -m http.server 8000
```

Depois aceda a `http://localhost:8000`.
npm i
